## 脚本思路
1、用socket把域名解析为IP地址

2、读取字典，将子域名与主域名拼接成完整的域名

3、用线程池提高解析效率

## 函数
_, _, ips = socket.gethostbyname_ex(dns)，返回主机名，别名，IP地址列表三元组

```text
    with ThreadPoolExecutor(max_workers=workers) as pool:
        futures = [pool.submit(resolve,dns) for dns in candidates]
        for future in as_completed(futures):
            dns, ips = future.result()
```            
多线程块， .submit（）提交函数和对应参数， as_completed()根据完成顺序来排序， .result()输出结果
